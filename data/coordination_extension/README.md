# Extended coordination data

`111D/` contains the final two-protocol DeepSeek comparison and actual dialogue messages. `111BC/C_*` contains the final feedback comparison, and `111BC/B_*` contains fault diagnostics. `111A/` contains source-level and individual assignment-selection observations; `timing/` contains the associated decision-time measurements. Folder identifiers are stable data keys, while the paper uses descriptive experiment names. Read each folder's English guide for its population and endpoints.
